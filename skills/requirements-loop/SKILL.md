# Requirements Loop

Mode: `requirements`

Inputs: baseline/current, source materials, root feature requirements, relevant neighboring features.

Writes: root requirements, slices, FE/BE packs, cross-feature impact section, task candidates, domain impact, consistency backlog.

Rules: root requirements are authored; slice packs are derived; local stale tails block completion.

Validation: context, trace, links, stale-term sweep, Russian-language check, and explicit coverage of every cross-feature impact.
